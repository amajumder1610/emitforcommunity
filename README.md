# EMIT

Upload a video and share it with a link.

## Usage

1. Enter your passphrase and connect.
2. Choose a destination.
3. Upload your video and give it a title.
4. Share the link EMIT gives you.

Don't have a passphrase? Ask whoever manages this tool for one.

If a video is very large, or a destination has been used a lot already, an upload may fail — try a smaller file or a fresh destination.
